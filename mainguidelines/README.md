# Main guidelines

This folder is the shared source of project guidance. Root `AGENTS.md` is the agent entry point, and each month’s README records its specific decisions.

- [Organization](organization.md): monthly folders, versions, generated outputs, and stable URLs.
- [Workflow](workflow.md): content edits, original designs, builds, visual review, and staging.
- [Email standard](email-standard.md): Ken Anderson’s email requirements and the delivery checklist.
- [Brand and editorial](brand-and-editorial.md): Rainmaker identity, tone, images, and issue-specific precedent.
- [Historical workflow](legacy-workflow.md): preserved earlier instructions for reference; the current files above take precedence.

Ben produces one company feature each month. Each new month gets an original layout. Every issue and content version gets both a normal web edition and a separately generated email edition.
